# SDD — Feature: Account

## 1. Resumen
Feature aislada para administración de cuenta.

## 2. Repositorio
- `AccountRepository`: CRUD de `SocialUser` con `createAccount`, `getAccount`, `updateAccount`, `deleteAccount`.

## 3. UI
- `AccountPage`: placeholder “Caso de uso aislado: cuenta todavía no integrada.”

## 4. Requisitos
| ID | Requisito | Evidencia |
|-----|-----------|-----------|
| RF-ACC-01 | Crear/Leer/Actualizar/Eliminar cuenta de usuario. | métodos en `AccountRepository`. |
